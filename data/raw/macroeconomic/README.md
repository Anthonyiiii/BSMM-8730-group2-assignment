# Macroeconomic Data

This folder contains Canadian macroeconomic datasets
used to evaluate the financial and market performance
of SmartCentres REIT.

## Data Sources

- Bank of Canada Valet API
- Statistics Canada Web Data Service API

## Datasets

- Policy Interest Rate
- Canada 5-Year Government Bond Yield
- Canada 10-Year Government Bond Yield
- Consumer Price Index (CPI)
- Monthly Retail Sales

## Target Analysis Period

January 2023 to September 2026.

The original datasets are retained for data validation,
cleaning, and further analysis.
